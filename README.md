# PKMN-save-editor 🇮🇹 🇬🇧
made with Claude
With this HTML file, you can edit hack ROM save files. Currently supported:
 * Odyssey (ITA/ENG)
 * Unbound
 * SoulSilver (or SoulGold)
 * Emerald Mini
 * Radical Red
 * Super Mariomon

Additionally, it supports PokéBank. You can transfer Pokémon inside the file and retrieve them whenever you want.

Info patch:
UNBOUND
• Brings back local trading (link cable) at the Cable Club on the Pokémon Center's second floor: the Trade option works again and the Cable Club rooms (Trade Center and Colosseum) are restored.

• Works only with the Pokémon Unbound v2.1.1.1 ROM and must be applied with an IPS patching tool (for example Lunar IPS or Floating IPS). Trading stays blocked in Insane, Randomizer and Sandbox modes.


SUPER MARIOMON 
• Fixed Giga Bowser's sprite while in battle.



ODYSSEY
• Added the portable PC. When you interact with the PC you will get an item: the Portable PC. It will be in the bag, among the basic items.

• Added the sprites of the final boss's Pokémon.


SOULGOLD
• Added the portable PC. When you interact with the PC you will get an item: the Portable PC. It will be in the bag, among the basic items.


Additionally, it supports PokéBank. You can transfer Pokémon inside the file and retrieve them whenever you want.

If you use Poké Bank, remember to download the new updated HTML file and replace it with the one you have. The Pokémon will be inside the new file.

Make sure to always back up your save files and games if you apply patches.
All changes take place locally. The file also works offline.
